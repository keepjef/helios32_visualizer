Helios Lidar PCAP Player

Высокопроизводительный плеер для визуализации данных лидара Helios из файлов
.pcap и .pcapng. Оптимизирован для работы на macOS с файлами объемом в десятки
гигабайт.

🚀 Основные возможности

  - Мгновенная работа с большими файлами: Благодаря предварительной индексации,
    файлы по 30–50 ГБ открываются и перематываются без задержек.
  - Высокая скорость отрисовки: Использует движок Vispy (OpenGL) для
    визуализации миллионов точек при 60 FPS.
  - Векторизованный парсинг: Обработка пакетов реализована на NumPy, что в
    десятки раз быстрее обычных циклов Python.
  - Гибкая настройка: Изменение UDP-порта, размера точек и скорости
    воспроизведения (0.25x – 4.0x) прямо в интерфейсе.
  - Умная раскраска: Точки окрашиваются в зависимости от интенсивности отражения
    (Градиент: Синий → Желтый → Красный).

🛠 Установка и настройка

1. Требования

  - Python 3.9 или выше.
  - Операционная система: macOS (проверено), Windows или Linux.

2. Создание окружения (рекомендуется)

Откройте терминал в папке проекта:

python3 -m venv venv
source venv/bin/activate

3. Установка зависимостей

Установите необходимые библиотеки одной командой:

pip install pyside6 vispy dpkt numpy

📂 Структура проекта

Для корректной работы импортов убедитесь, что файлы расположены следующим
образом:

lidar_project/
├── main.py                # Точка входа в приложение
├── parser/
│   ├── __init__.py        # Пустой файл
│   ├── frame_index.py     # Логика сканирования и индексации PCAP
│   └── helios_pcap_parser.py # Быстрый парсер данных лидара
├── cache/
│   ├── __init__.py        # Пустой файл
│   └── frame_cache.py     # Кэширование кадров в оперативной памяти
├── viewer/
│   ├── __init__.py        # Пустой файл
│   └── lidar_player.py    # Графический интерфейс и 3D-движок

Важно: Файлы __init__.py должны быть в каждой папке, чтобы Python видел их как
модули.

🖥 Использование

1.  Запуск:

    python3 main.py

2.  Первоначальная настройка в интерфейсе:

      - Введите UDP Port (по умолчанию 2368), на котором работал ваш лидар.
      - Нажмите Open PCAP / PCAPNG и выберите ваш файл.

3.  Индексация:

      - При первом открытии файла программа создаст индекс кадров (в терминале
        появится шкала прогресса или лог). Рядом с вашим .pcap появится файл
        .index.npy.
      - В следующий раз этот же файл откроется мгновенно.

4.  Управление:

      - Play/Pause: Запуск и остановка анимации.
      - << / >>: Замедление или ускорение воспроизведения.
      - Point Size: Регулировка жирности точек для лучшей видимости.
      - Мышь: Вращение облака точек.
      - Скролл: Приближение/удаление (Zoom).
      - Правая кнопка мыши / Cmd + Мышь: Перемещение камеры (Pan).

⚠️ Решение проблем (Troubleshooting)

  - Ошибка "ModuleNotFoundError": Убедитесь, что вы запускаете main.py из
    корневой папки проекта и в подпапках созданы файлы __init__.py.
  - Прочитано LiDAR пакетов: 0:
      - Проверьте, правильно ли указан UDP-порт (посмотрите порт в Wireshark).
      - Если порт верный, удалите файл .index.npy и попробуйте открыть файл
        снова.
  - Приложение зависает при открытии: На macOS такое бывает, если файл
    поврежден. Посмотрите в терминал — там будет выведена причина
    ошибки.
  - Низкий FPS: Если у вас очень много точек, уменьшите Point Size до 1 или 2.

💡 Совет

Если вы хотите сбросить индекс (например, если вы указали неверный порт и индекс
построился неправильно), просто удалите файл с расширением .index.npy в папке,
где лежит ваш PCAP. Скрипт перестроит его автоматически при следующем
открытии.
